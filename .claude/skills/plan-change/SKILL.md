# Plan Change

1. Inspect the relevant implementation, tests, contracts, and docs.
2. Identify affected user-visible behavior and invariants.
3. Classify risk as low/medium/high.
4. Define required verification layers.
5. Produce a small implementation plan with explicit success criteria.
6. Do not edit code unless the invoking workflow explicitly allows implementation in the same task.
